# Проверка хранения вывода

Запуск из корня репозитория:

```sh
.sdk/dotnet run --project tests/ExecServer.Storage.Tests/ExecServer.Storage.Tests.csproj
```

Это отдельный исполняемый harness без сторонних пакетов. Он компилирует настоящий
`OutputBuffer.cs` напрямую, поэтому может проверять хранилище до готовности HTTP-хоста.
На Windows используется установленный соответствующий `dotnet`, без префикса `.sdk/`.

Проверяются сохранение всех байтов при переходе из памяти в файл, чтение по
смещениям, пробуждение при записи/EOF/ошибке, отмена ожидания, параллельные чтения,
отказ создания spill-файла без потери уже накопленного префикса и завершение
активного чтения перед удалением файла. Каждый запуск использует собственный
временный каталог и удаляет только его.

API хранилища не интерпретирует UTF-8 и не определяет политику удаления запуска:
это ответственность HTTP-контракта и менеджера запусков. Spool-каталог должен
быть создан и защищён владельцем сервиса; хранилище не принимает пути от клиента,
использует случайное имя `BlobId.blob` с CreateNew и приватными Unix-правами.
