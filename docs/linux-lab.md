# Чистая Linux-лаборатория

Стенд создаётся отдельно от существующих машин. Для хоста нужны libvirt/QEMU,
virt-install, cloud-localds, curl, sha256sum и действующий локальный SSH-ключ
`~/.ssh/id_ed25519.pub`. Скрипт использует sudo только для собственной новой ВМ,
диска и seed, не меняет существующие гостей или сетевые настройки.

Создание: `bash scripts/create-linux-vm.sh`. Имя — `exec-server-test-20261116`,
Ubuntu 26.04, 2 vCPU, 4 ГиБ RAM, диск 35 ГиБ с backing image. Базовый образ
закреплён SHA-256 в скрипте; официальная подпись SHA256SUMS проверена ключом
Ubuntu Cloud Images `D2EB44626FDDC30B513D5BB71A5D6C4C7DB87C81` при подготовке.
API-ключи и SSH-ключи в публичный репозиторий не входят. Рабочие файлы —
`.artifacts/linux-vm`, кэш образа — `/mnt/data/exec-server-lab-inputs`.

Сначала копируется только self-contained бинарник. Проверяется отсутствие
`dotnet` и запуск API. Последующие установки пакетов, установка SDK и сборка
переданного исходного проекта выполняются через ExecServer, по одному запросу
на команду с сохранением ID и кода завершения. SSH остаётся транспортом файлов,
туннелем и первоначальным способом запустить сам сервер.

Остановка своей машины: `sudo virsh shutdown exec-server-test-20261116`, затем
проверка `sudo virsh domstate exec-server-test-20261116`. Полное удаление стенда
производится отдельным явно выбранным действием: после остановки снять определение
ВМ и удалить только её qcow2 и seed. Общий базовый образ не удаляется. Этот
документ не разрешает удаление чужих машин или общего кэша.
